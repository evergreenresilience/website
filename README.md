# ERI Website

A portfolio website built with **React** and **Vite** as the build tool, deploying via **GitHub Pages**.

## Getting Started

To customize this template into your own website:

**Data & Content** — Edit `src/data.js` to replace all text content, links, and section configurations.  
**Images** — Drop your own images into `public/images/` and update the file references in `data.js`.  
**Aesthetics** — Adjust colors, fonts, and styling in `src/App.jsx` (inline styles) or add a CSS file and import it.

```bash
npm install
npm run dev
```

To deploy: run `npm run deploy` (requires the `gh-pages` package and a GitHub repository).
